# Image Processing Gallery

Side-by-side comparison of all 100 images processed by the Java 21 and Rust Lambda functions. Each row shows the original alongside both runtime outputs at 70% compression.

> **Benchmark context:** Both functions received the exact same input via SNS Fanout and processed images with identical compression settings (70%). Visual differences, if any, reflect codec-level implementation differences between the Java `ImageIO` and Rust `image` crates.

---

## How to Read This Gallery

| Column | Description |
|--------|-------------|
| **Original** | Source image (800×600 JPEG), unmodified |
| **Java 21** | Output from `Java 21` Lambda (`ImageIO` + 70% compression) |
| **Rust** | Output from `Rust` Lambda (`image` crate + 70% compression) |
